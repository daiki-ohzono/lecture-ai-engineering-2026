## 宿題

- 取り組んだレベル：基礎
- やったこと：app/agent.pyのINSTRUCTIONSに以下を書き加えた．

        - 確認問題を求められたら、make_quiz を使う。
        - まず問題文とヒントを提示する。
        - その後、答えを提示する。

- 結果：uv run python -m app.agent --trace "第2回の内容から確認問題を1問出して"の確認問題を以下に提示する．

        第2回の内容から確認問題をお出しします！

        **【確認問題】**
        次の用語の定義は何でしょうか？

        * **事前学習**

        **【ヒント】**
        モデルを本格的に訓練・利用する前の「最初の段階」で行われるプロセスです。大量のデータを使って「次に来る言葉（トークン）」を予測させることで、モデルに言語の基礎知識や一般的な常識を覚えさせます。

        ---

        **【答え】**
        大量の汎用テキストで、次のトークンを予測するようにモデルを学習させる最初の段階。言語の知識や一般的な常識の多くはここで身につく。

        （第2回）

- 気づき・疑問：

        はじめは、INSTRUCTIONSに「make_quizによって確認問題を出した場合は、問題とヒント、答えを表示する。」とだけ記述していた。しかし、この状態で何度か実行したところ、確認問題の答えがヒントのすぐ下に表示されてしまい、利用者が答えを考える前に見えてしまうことがあった。
        そこで、問題と答えの間に適切な余白を設ける方法をCopilotに質問したところ、INSTRUCTIONS内で表示する要素を複数行に分けて記述する方法が提案された。実際にこの方法を試したところ、問題と答えの間に余白が設けられ、以前よりも使いやすい表示になった。
        この経験から、プロンプトは指示の内容だけでなく、記述方法によっても出力結果が変化することが分かった。また、期待どおりの出力を得るためには、実際の動作を確認しながら、指示の与え方を工夫することが重要だと感じた。
